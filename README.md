# StoreManagement

Application de gestion de magasin développée en C# avec .NET 10 LTS, Windows Forms, SQLite et Microsoft.Data.Sqlite.

## Architecture

- Domain
- Application
- Infrastructure
- Presentation

## Stack

- C#
- .NET 10 LTS
- Windows Forms
- SQLite
- Microsoft.Data.Sqlite

## Point d'entrée

La solution contient un projet `StoreManagement.Presentation` qui lance l'application WinForms.
